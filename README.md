# Tageswerte

Kleine Offline-Web-App (PWA) für tägliche Gesundheitswerte: Blutdruck morgens/abends, Gewicht (mit BMI und Tendenz),
Sport, Schritte/PAI, Kalorien, Trainings-Form/Belastung und Schlaf. Tage vor- und zurückblättern, Diagramme pro Bereich,
Export als CSV (Excel) und JSON-Sicherung.

Alle Daten bleiben lokal auf dem Gerät (IndexedDB). Dieses Repository enthält nur den Code.
Diagramme: [Chart.js](https://www.chartjs.org) 4.5.1 (MIT), lokal eingebunden.

App: https://kamart285.github.io/tageswerte/
